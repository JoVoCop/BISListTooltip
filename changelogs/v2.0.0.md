## v2.0.0

BIS List Tooltip is back for WoW Forever, featuring an all-new website, [bislist.io](https://bislist.io), that makes creating and sharing your BIS lists easier than ever.

* Multiple lists: switch between built-in lists and lists you import. The active list is remembered per character.
* Import lists from bislist.io by pasting the import string into the options panel (`/blt`).
* Guild update notices: when a guildmate has a newer version of a list you use, you get a popup, once per list version and at most one popup per list per session, never in combat or an instance.
* Tokens: hovering a token shows the lines of the items it can be turned into.
