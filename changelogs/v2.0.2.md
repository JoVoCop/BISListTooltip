## v2.0.2

Random suffixes:

* Lists can now name a specific random suffix, such as "High Councillor's Pants of Shadow Wrath". The tooltip shows that entry only on the item with that suffix, not on every version of the item.
* Suffixes are matched by ID, so they work in every game language.
* Lists without suffixes work exactly as before.

Updated the built-in lists:

* Updated "Forever Phase 1" to the latest version from [bislist.io](https://bislist.io).
