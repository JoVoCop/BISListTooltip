## BIS List Tooltip

BIS List Tooltip is back for WoW Forever, featuring an all-new website, [bislist.io](https://bislist.io), that makes creating and sharing your BIS lists easier than ever.

### Features
* BIS information for every class displayed in a tooltip. No more alt-tabbing to compare items.
* Customizable class display. Only care about your class? No problem.
* Make your own lists on [bislist.io](https://bislist.io). Rank the items in each slot for any class and build, label them your way (Best, Optional, Pre-BIS or anything else) and share a link with your guild.
* Import any list in seconds. Copy its import string on bislist.io, type `/blt` in game and paste it.
* Switch between lists at any time. Each character remembers its own.
* Select lists are included in the addon, so you can keep them up to date just by updating the addon.
* Meaningful version history. bislist.io shows what was added, removed or re-ranked between versions of a list.
* Guild update notices. If a guildmate has a newer version of a list you use, you'll get a notification.
* Tokens show the BIS lines of the items they can be turned into.

### Getting started
1. Install BIS List Tooltip.
2. Find a list on [bislist.io](https://bislist.io), or make your own, and press **Copy import string**.
3. In game, type `/blt`, paste the string into the import box and press **Import**.
